# Job Application Tracker — Elijah Sterling

COP4751 full-stack database course project. This application tracks companies, job opportunities, applications, professional contacts, and skill-to-job matching.

## Technology
- Python 3 and Flask
- MySQL 8+ with foreign keys and JSON columns
- HTML templates with responsive CSS
- `mysql-connector-python`

## Features
- Dashboard statistics and recent application activity
- Full create, read, update, and delete operations for Companies, Jobs, Applications, and Contacts
- Relationship-aware dropdowns and validation
- Cascade deletes for dependent records
- Job Match page ranks saved jobs using a skills overlap percentage
- Parameterized SQL statements for submitted values

## Requirements
- Python 3.10+
- MySQL Server 8.0+
- Git (recommended)

## Setup (fresh clone)
1. Clone the repository and change into its directory:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   cd job_tracker
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # macOS/Linux
   source .venv/bin/activate
   # Windows PowerShell
   .venv\Scripts\Activate.ps1
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create the database and tables in MySQL:
   ```bash
   mysql -u root -p < schema.sql
   ```
5. Configure your database connection. Set environment variables in your shell (do not commit passwords):
   ```bash
   export DB_HOST=localhost
   export DB_PORT=3306
   export DB_USER=root
   export DB_PASSWORD='your_mysql_password'
   export DB_NAME=job_tracker
   ```
   Windows PowerShell:
   ```powershell
   $env:DB_HOST="localhost"
   $env:DB_PORT="3306"
   $env:DB_USER="root"
   $env:DB_PASSWORD="your_mysql_password"
   $env:DB_NAME="job_tracker"
   ```
6. Start Flask:
   ```bash
   python app.py
   ```
7. Open `http://127.0.0.1:5000` in your browser.
